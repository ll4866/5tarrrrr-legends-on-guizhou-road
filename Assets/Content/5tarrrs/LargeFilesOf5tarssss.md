# LARGE FILES INFO:

## File 1: Standing Soldier
This 3D model represents a single soldier that the user interacts with in the project. It is also intended to be 3D printed as a physical object for the final presentation, connecting the digital experience with a tangible form.

## File 2: Group Marching
This 3D model represents a group of soldiers marching along Nanjing Road in 1949, shortly after the “sleeping on the streets” event. It is used to visually convey the historical moment and the collective discipline of the soldiers.

## Additional Large File: Local LLM Model
The project uses a locally hosted language model for chatbot interaction. Due to its large file size, it is not included directly in the repository.

### Setup Instructions:
1. In the Unity Hierarchy, locate the object containing the LLM component.
2. In the Inspector panel, find the LLM script.
3. Click "Download Model".
4. Navigate to Tiny Models and select "Llama 3.2 1B".

This model enables the chatbot functionality within the project.
